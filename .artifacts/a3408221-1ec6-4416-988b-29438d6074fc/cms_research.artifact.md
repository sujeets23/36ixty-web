# CMS Pricing & Free Open-Source Options Research

When looking for a **100% free, open-source CMS** that you can host yourself without recurring SaaS subscription costs, several industry-leading options stand out.

---

## 1. Top 100% Free & Open-Source (Self-Hosted) CMS Options

### **1. Payload CMS (Community Edition)**
- **License / Pricing:** Open-source (MIT core). **100% free** when self-hosted.
- **Hosting:** Run on any Node.js server (Docker, VPS, Railway, Render, AWS, etc.) backed by MongoDB or PostgreSQL.
- **Why it fits React/TS apps:** Built natively in TypeScript and React. You can write your collections, fields, and access control entirely in TypeScript right alongside your project.
- **Admin UI:** Modern React-based admin dashboard built-in.

### **2. Directus**
- **License / Pricing:** Free & open-source community edition.
- **Hosting:** Self-hosted via Docker using PostgreSQL, MySQL, SQLite, or Oracle.
- **How it works:** Instantaneously turns any SQL database into a headless CMS with a gorgeous Vue.js admin app, REST API, and GraphQL API.
- **Why it fits:** Great if you want a robust data management dashboard without writing backend code.

### **3. Strapi (Community Edition)**
- **License / Pricing:** Free, open-source community edition for self-hosting.
- **Hosting:** Node.js server with PostgreSQL, MySQL, or SQLite.
- **Admin UI:** Fully customizable Node/React admin dashboard.
- **Why it fits:** Mature ecosystem with plugins for content localization, media libraries, and role-based permissions.

### **4. Headless WordPress**
- **License / Pricing:** GPLv2 (100% free and open source).
- **Hosting:** Any PHP/MySQL hosting.
- **API:** Exposed via WP REST API or WPGraphQL.
- **Why it fits:** Unmatched user-friendly content editing for non-technical editors, combined with a headless frontend.

## 2. Comparison of SaaS vs Open-Source Pricing

| CMS Option | Pricing Model | Self-Hosted Cost | Cloud / Managed Cost |
| :--- | :--- | :--- | :--- |
| **Payload CMS** | Open Source (MIT) | **$0 / free** (on your VPS/Docker) | Free tier available; Pro starts at ~$35/mo |
| **Directus** | Open Source | **$0 / free** (on Docker) | Cloud starts at ~$15/mo |
| **Strapi** | Open Source | **$0 / free** (Community Edition) | Cloud starts at ~$29/mo |
| **Sanity.io** | SaaS (Free Tier available) | N/A (Cloud only) | Free up to generous limits; Team starts at $99/mo |
| **Contentful** | SaaS | N/A (Cloud only) | Free tier limited; Team starts at $300/mo |

---

## 3. Recommendation for 36ixty-web
For a **100% free, open-source setup**, **Payload CMS** or **Directus** running on a free-tier VPS or local Docker container provides a powerful admin dashboard and API without any licensing fees.
